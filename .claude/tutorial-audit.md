# Tutorial/Code Consistency Audit Ledger

Goal: form a complete Agent development tutorial that goes from shallow to deep. Check each chapter's tutorial against the matching `code/chapters/chNN`. Keep the explanation deep but easy to follow.

## Tools

- `code/scripts/chapter-delta.mjs [from] [to]`: the snapshot difference between adjacent chapters. It confirms "each chapter adds only one capability".
- `code/scripts/verify-tutorial-refs.mjs [ch...]`: whether the paths, npm scripts, and file names that the tutorial references really exist.
- `code/scripts/verify-tutorial-snippets.mjs [ch...]`: whether a TS code block in the tutorial finds matching source code in this chapter's snapshot.
